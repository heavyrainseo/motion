# 모션 그래픽 HTML 파일 저장소

주로 meta.ai에서 생성

## 사용 방법
1. 레포 setting - pages 에서 main을 페이지로 지정
2. 레포에 *.html 파일 업로드
3. 깃허브id.github.io/레포명/파일명으로 접속
