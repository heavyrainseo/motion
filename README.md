# 모션 그래픽 HTML 파일 저장소

주로 meta.ai에서 생성  
예 : 선형회귀 원리로, mse의 기울기에 대한 편미분 이차함수에서 접선이 기울기 0으로 점점 내려갈 때 선형회귀 직선의 기울기가 변하면서 최적화되는 gradient descent 알고리즘을 애니로 만들어 줘. 파일명은 lrgd.html이야. 학습률 범위는 0.001~0.1로, 단계는 0.001이야.   

## 사용 방법
1. 레포 setting - pages 에서 main을 페이지로 지정
2. 레포에 *.html 파일 업로드
3. 깃허브id.github.io/레포명/파일명으로 접속   
[예](https://heavyrainseo.github.io/motion/Lrgdsrc.html)
